# Finance App: Features

## Target user
Monthly salary kittunna, spending plan illathe month-end-il cash theerunna aalukal.

## Core
- Auth + profile: salary amount, salary date. Value: cycle salary date-il thudangum.
- Transactions (UPI/ATM/cash/card): Value: ella spend-um oru idathu.
- Categories (default + custom): Value: evide cash pokunnu ennu ariyaam.
- Paste-SMS parser: Value: bank SMS paste cheythal auto entry.
- Duplicate detection (UPI ref): Value: oru transaction randu thavana varilla.
- CSV import: Value: pazhaya data ore thavana kondu varaam.

## Planning
- Monthly budget: Value: category-wise limit.
- Safe-to-spend + today's limit: Value: innu ethra spend cheyyam ennu ariyaam.
- Goals + one-year plan: Value: ethra save cheyyanam ennu app parayum.
- Recurring bills: Value: rent/EMI marannu pokilla.
- Sinking funds: Value: yearly expense monthly split.
- Cash tracking: Value: ATM-il ninnu edutha cash track.

## Alerts
- 80% / 100% budget, ATM mismatch, daily overspend
- In-app + email alerts
- Month-end report + insights

## Quality
- Dashboard charts, responsive + PWA
- Tests, Docker, CI/CD, deploy

## Phase 2 (not in Weeks 1-12)
- React Native Android, auto SMS capture, push notifications

## Out of scope (for now)
- Multi-user / family accounts, investments, bank API integration
